# Additional 44, 45 and 47 reusable assets

Thirty-six static editable collections and twenty-eight scene palette parameter variants. These are reference-informed approximate blockout assets; dimensions are authored metres, not independently calibrated measurements. Original scenes and generated people are excluded from the library.

The three immutable libraries are selected by the parent registration task. `registry_ready.json` contains the exact registry entries and curated annotations; `source_coverage.json` classifies every source object and links repetitions to concrete exported IDs. `material_palette.json` records every source material disposition, including shell-only colors and excluded render/person utilities.

Furniture remains separate editable mesh parts. Modifiers and placement scales are baked. No room animation, humans, external image dependencies or operative cabinet mechanisms are required. Wall fixtures use explicit mount centers; floor and tabletop objects use bounds-centered base origins. All directional collections use front -Y and up Z after normalization.

## Reviewed asset-copy refinements

Source files were never edited. Portable copies fix the44 upholstered back, clear-chair/table support junctions and chandelier suspension;45 detached L module arrangement and pedestal junction;47 curtain mounting gap. See each scene subdirectory `refinements.json`. Initial views/manifests and reproduced initial libraries are kept in `runs/additional_assets_444547/20260911`; only selected final libraries are in this asset version.

## Validation

Every collection has oblique/top renders, bounds/unit-scale/material checks and save/reopen/reappend evidence in its `validation.json`. Native collection/material thumbnails are embedded in each library. Final source-integrity and library hashes are in `final_integrity.json`. Parent performs an independent registered `resolve_item` / `place_asset` audit after integrating registry and index.

Every exported asset and all palette swatches were visually reviewed. Simplifications remain intentional:44 stemware and45 vases are solid proxies, curtains rigid strips, artwork authored blank/abstract geometry, drawers static facades, and the45 sectional is a detachable modular L pair.

## Distribution scope and validation

All three library binaries match the validated source asset versions byte for byte.
Each scene includes `validation.json`, `provenance.json`, `refinements.json`,
coverage metadata and rendered previews. Source `runs/` and `scenes/` paths in
these records identify upstream evidence that is not bundled or required for use.
The source reference clips are not bundled. Generated scene copies, people, caches and historical validation
renders are omitted. The libraries contain no external image dependencies.

Agent scene closeout includes identifying newly authored reusable furniture and
materials, deduplicating against the catalog, validating extracted copies, and
updating the registry and search index. This is an agent workflow obligation;
there is no unattended extraction daemon. Repeated instances reuse their existing
asset IDs. Unvalidated candidates retain an explicit incomplete status.
