## 完整流水线完成契约

2026-09-20 作者明确：完整源人物重建须完成场景锚定、v2 世界后优化、人-物/脚-地接触优化、源投影/碰撞/滑动验证、最终集成场景。复用已验证场景/模型缓存，所有可见人物在范围内。诊断标签、摆放门失败或 GVHMR/v2 完成都不满足任务，要修复继续。真实外部阻碍须具体报告并标任务未完成。

v2 是完整请求默认（2026-09-22），native GVHMR 留作对照，运行 v2 不自动接受。独立参考/placement-only/motion-only 保留声明范围，见 [v2](WORLD_POSTOPT.md)。

初始以共享场景相机基、身体尺度 1 的固定刚性变换摆放，再同求解器处理预测 GVHMR 脚接触与有证据的有限物体接触。必须有源证据/实际表面，不给未触家具行人虚构目标。检查所有活跃帧地板/物体穿透、支撑滑动和代表投影。逐人 v2 相机一致性不等于共享摆放。全片缺强关键点时用低置信预测、小非零权重和稳健多帧重试；低分不免锚定，保留弱证据状态，用共享相机和接触验证，不虚构缺预测。

优先骨盆/髋和肩锚，再退到同人物任意可见关键点；缺髋肩不能丢整帧。经摆姿网格将部位表面观测变成整体平移约束并置信加权，不把腕/踝深度当骨盆。明确拒绝错人物/背景。密集相机不等于密集深度，保留匹配深度/置信/内参/源帧 ID/变换；缺中间产物重跑生产者并保存。

完整授权取代下方历史 opt-in；显式摆放/运动-only、审查/调试仍窄范围。Kimodo 默认禁补全。当前 translation-only 对比固定所有 GVHMR/v2 关节，是实验范围，不禁止上身接触优化。作者禁止腿修复和碰撞驱动改关节。整体接触平移可减穿透。有源支持肩/肘/腕拟合可考虑明确旋转速度/加速度正则和源姿态保留，本对比未执行。独立轨迹缩放/无关动作变化不属默认。见[全流程](REAL2SIM_PIPELINE_zh-CN.md)。

<a id="initial-native-motion-placement"></a>

## 初始原生运动摆放

保留源支持手/座/脚优化。全身平移含固定房间 Z 可以改善接触/穿透，全部关节/顶点同移，保留大小/局部姿态。时变修正正则，并联合看投影、速度/加速度、转换和滑动。不能因碰撞改关节或运行人类 6D 腿修复/腿 IK；无法同时满足接触时报告冲突，不扭曲动作。历史腿修复交付仍撤回。

初始为全片固定刚性、scale 1，是起始位置，不限制默认 v2/后续平移。保留时间、蒙皮前重采样旋转。合成 in-frame 不证明源可见性。

配置前端在 GVHMR 前提供已审查跟踪，SAM3/旧 SAMURAI 按当前路由。确认退出终止/隐藏，临时遮挡不隐藏。保留原生尺寸/局部关节；Pi3X 只参考，房间仍可编辑 Blender。Kimodo 用于新/改动作或记录的生成回退。旧外部臂 IK、视线地板吸附、逐帧朝向编辑继续退役。

## 显式请求的优化

## 历史原生-only 默认（2026-09-12，当前路线已取代）

当时用户简化路线：保留 GVHMR native global、大小/旋转，全片一固定刚性、scale 1；默认不做逐帧根/地板、轨迹优化、平滑/IK。

特定人物腿穿地，先只给该人物常量竖移：清单 actors[i].vertical_translation_m（米、room Z、正向上、默认 0）。对齐后全部顶点/关节/帧同偏移，其他人物/房间/相机不动。记录 ID、偏移、源/房间证据，不把命名人物偏移写代码。固定移保持轨迹差、跳跃和姿态，完整看剩余问题，不自动升级帧修正/IK。

run_contact.sh/contact_refine.py 当前默认此保 native，仍校验参数再现/源摆放。旧可复用求解器仅单独请求时 --refine-contact；历史授权不让自动支撑高度/腿 IK 成当前默认。见[调用范围](CONTACT_REFINEMENT_zh-CN.md)。

<a id="reference-video-default-and-priority"></a>

## 参考视频默认与优先级

源指导 Kimodo 用 **root > hands >= feet > text-only**；源视频提供根路线/有用手脚，文本给动作语义。稀疏选择且看真实源，缺可靠参考记录限制。

每原生 prompt 最多 10 秒，长片多段。交付连续动作并看源对照，包括手势、支撑、取景；保留原候选/剩余近似。智能体用 [SAM 技能](../.agents/skills/sam3d-motion-reference/SKILL.md)和[场景工作流](SCENE_WORKFLOW_zh-CN.md)选实现。text-only 保留文本入口。

<a id="choose-controls-by-task"></a>

## 按任务选择控制

| 需求 | 首选控制 |
| --- | --- |
| 源视频人物动作 | GVHMR 估计、房间对齐、导入制作 Blender 房间 |
| 显式文本行走/转向/手势 | 文本及请求房间/路径的根指导 |
| 接触指定架/物或手脚目标 | 必要时刻稀疏原生 Kimodo 末端约束 |
| 关键时刻特定全身姿态 | 末端指导不足时才稀疏原生全身关键帧 |

视频辅助先看源，在有意义动作变化处分段再选文本。已接受 10 秒走+5 秒手势是历史例，不是新源默认或对应保证。记大致动作起终、走/停、朝向、活动臂。SAM 估计变目标前审查；更多观测不证明时间对应。

2026-09-09 g0070 redo（历史/外部，不随包）用户优先原生 Kimodo 于人物/家具避碰，授权推断摆放；该路线允许碰撞，不改路线/姿态为过家具检查。除动作明确需要并授权，关闭逐帧地板吸附。保留原始、蒙皮前时间重采样，显示重中心与保存房间动画区分。此偏好仅生成人物，不免静态家具/道具支撑挂接检查。

历史 g0070 例外：稀疏根指导仍朝向/运动相反，交付改文本-only和整个原生轨迹固定摆放。优先轨迹保留时删扭曲动作路径约束，不加更多姿态。隐藏房间预览可看动作，不重规划。此历史例不是新参考视频默认。

匹配源时间看转换/释放/放下，动作近似与几何/帧数/解码分开。不匹配时改原生文本/必要稀疏指导并再生成，不外部 IK/关键朝向修输出。报告手高/朝向/时间差，不称准确重建。无遮挡 SMPL-X 预览可揭示房间遮挡的动作。

不为让配方更详细而加接触/姿态约束；给重心变化/手势空间，不在无需固定结尾锁全程根。近似动作不要求拟合重建参考人物姿态。

<a id="native-3d-targets-for-contact"></a>

## 接触的原生三维目标

Kimodo 生成支持稀疏全身/末端约束。手约束含腕位置/旋转和手端位置，并在选帧约束平滑根，模型围绕目标生成余身。见[官方约束](https://research.nvidia.com/labs/sil/projects/kimodo/docs/key_concepts/constraints.html)。

必要架触摸先仅必要接触关键帧（如 2–3 合适时刻），制作可达房间目标，以路线同世界对齐/尺度转 Kimodo Y-up 米坐标并生成周边运动。这是起始实验，不是验证约束数/平滑保证。

JSON 存 pose/root 和 right-hand/end-effector 等类型，后者选相关末端；pose 形数组不自动锁全身，也不能假设仅任意腕 XYZ。制作时查骨架关节名和 [JSON 字段](https://research.nvidia.com/labs/sil/projects/kimodo/docs/user_guide/constraints.html)，避免手约束携根导致每手势帧固定根。

总体方向用初朝向/文本/路线；原生 pose key 只用于必要朝向/姿态事件。加约束前看靠近/接触/释放/段连接，在实际房间检查手可达、脚接地、净空和连续。

<a id="retired-external-correction-method"></a>

## 已退役的外部修正方法

首版生成后臂 IK/关键帧朝向编辑已移出支持工作流，不用 refine_body.py 作配方/回退/新场景起点。旧产物/历史记录只描述旧结果。

不禁 Kimodo 内建 motion correction，它是生成独立部分，在接受 10+5 例开启。稀疏原生约束仍可冲突/可见接缝，不是通用抖动解。记录试验 3 个腕目标误差约 0.9–1.9 cm，但结尾 jerk 高于接受基线；空间准确与平滑分开，泛化前看范围/证据。

<a id="reusable-placement-and-contact-acceptance"></a>

## 可复用摆放和接触验收

共享方法适用所有场景/人物，不把命名人物、参考特定时间窗或手调深度偏移写共享修正。源特定观测/排除带证据放清单，通用策略一视同仁。

真实源观测摆放在接触前后检查。低覆盖未验证，坏窗口不能被总中位藏；身体 scale 1、源形状固定。接触平移可改根 XYZ 保关节，需审轨迹。时间探针不授权逐帧视线接地或宣称解漂移。见[共享方法](CONTACT_REFINEMENT_zh-CN.md)。
